### Trivy

Trivy помогает обнаруживать уязвимости в зависимостях вашего приложения. Это простой и комплексный сканер уязвимостей для контейнеров и других артефактов.

#### Установка

Для установки Trivy можно использовать следующий Helm-чарт:

```bash
helm repo add aqua https://aquasecurity.github.io/helm-charts/
helm repo update
helm install trivy-operator aqua/trivy-operator --namespace trivy-system --create-namespace --version 0.23.2
```

#### Удаление

Чтобы удалить Trivy, используйте следующую команду Helm:

```bash
helm uninstall trivy-operator --namespace trivy-system
```
