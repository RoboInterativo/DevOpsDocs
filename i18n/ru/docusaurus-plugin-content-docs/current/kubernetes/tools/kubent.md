Kubent (Kube No Trouble) — это простой инструмент для проверки того, используете ли вы в кластере устаревшие версии API, и, следовательно, нужно ли сначала обновить рабочие нагрузки перед обновлением кластера Kubernetes.

## Ресурсы

- [Репозиторий Kubent на GitHub](https://github.com/doitintl/kube-no-trouble)

## Установка

Вы можете установить Kubent на macOS с помощью Homebrew.

```bash
brew install kubent
```
