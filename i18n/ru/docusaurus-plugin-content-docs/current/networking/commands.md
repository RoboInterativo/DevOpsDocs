### Ping

Ping — это команда, которая используется для проверки связи между двумя устройствами. Она отправляет ICMP-запросы (echo requests) целевому устройству и ожидает ICMP-ответы (echo replies). Если целевое устройство отвечает, значит соединение работает.

```bash
ping google.com
```

### Traceroute

Traceroute — это команда, которая используется для определения пути, который пакеты проходят до целевого устройства. Она отправляет ICMP-запросы целевому устройству и ожидает сообщения о превышении времени (time exceeded). Если целевое устройство отвечает, значит соединение работает.

```bash
traceroute google.com
```

### Nslookup

Nslookup — это команда, которая используется для определения IP-адреса по доменному имени. Она отправляет DNS-запрос DNS-серверу и ожидает ответа.

```bash
nslookup google.com
```

### Netstat

Netstat — это команда, которая используется для отображения сетевых подключений и таблиц маршрутизации. Её можно использовать для поиска открытых портов на устройстве.

```bash
netstat -tulpn
```

### Hostname

Hostname — это команда, которая используется для отображения имени текущего хоста.

```bash
hostname
```
