Kubernetes Playground — это веб-среда Kubernetes, которая позволяет изучать Kubernetes и экспериментировать с ним. Это отличный способ начать работать с Kubernetes, не устанавливая его на локальную машину.

- [labs.play-with-k8s.com](https://labs.play-with-k8s.com/)
